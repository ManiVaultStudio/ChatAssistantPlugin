# Changelog

## 1.0.0

- Native ManiVault action controls, accessible themes, rich tooltips and optional animations.
- Searchable command palette and preferences; compact layouts and nonmodal settings.
- Saved chats with rename, pin, grouping, filtering, sorting, branching and context linking.
- Right-click chat, message and chart menus; Delete and F2 shortcuts.
- Reversible question resubmission and direct editing of saved questions/replies.
- 160 replaceable suggested questions organized by plugin, viewer/project and tutorial workflow.
- Per-user, per-installation application-data storage; explicit read-only legacy import.
- Resident GPU inference with context preparation, pause/resume/stop and native task progress.
- Coalesced Markdown rendering, bounded transcript widgets and on-demand stored-chat loading.
- Verified model packages, dependency notices, build presets and documented platform validation limits.
